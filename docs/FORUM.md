# Форум

Форум сервера Azimut: разделы → темы → сообщения. Читать может любой посетитель,
писать — только вошедшие в мастер-аккаунт. Модерация (закрепление/закрытие тем,
удаление, разделы) — у админов (`NUXT_ADMIN_LOGINS`).

Интерфейс локализован (ru/en, `app/locales`: `forum`); контент форума (названия
разделов, темы, сообщения) не переводится — это пользовательские данные.

## Страницы

| Адрес                  | Что показывает                                            |
|------------------------|-----------------------------------------------------------|
| `/forum`               | Список разделов со счётчиками и последней активностью     |
| `/forum/<section>`     | Темы раздела с пагинацией, форма новой темы (для вошедших)|
| `/forum/topic/<id>`    | Тема: первое сообщение, ответы, форма ответа, модерация   |
| `/admin/forum`         | Управление разделами (только админ)                       |

Пункт «Форум» добавлен в главное меню (`app/data/site.ts`: `nav`).

## База данных

Таблицы лежат в базе логин-сервера (`la2`, там же, где `master_accounts`):
`forum_sections`, `forum_topics`, `forum_posts`. Схема и стартовые разделы —
`server/database/forum.sql` (идемпотентный: `CREATE TABLE IF NOT EXISTS`, разделы
добавляются только в пустую таблицу).

### Создание таблиц (один раз вручную)

У пользователя сайта `cms_register` есть `SELECT/INSERT/UPDATE/DELETE` на `la2.*` —
этого достаточно для работы форума, но **не для создания таблиц**. Право `CREATE`
нужно выдать отдельно или выполнить скрипт под привилегированным пользователем MySQL:

```bash
# вариант 1: под админом БД (из каталога проекта)
mysql -h ХОСТ -u PRIVILEGED_USER -p la2 < server/database/forum.sql

# вариант 2: выдать CREATE пользователю сайта, выполнить скрипт, при желании забрать право
mysql -h ХОСТ -u PRIVILEGED_USER -p -e "GRANT CREATE ON la2.* TO 'cms_register'@'%'; FLUSH PRIVILEGES;"
mysql -h ХОСТ -u cms_register -p la2 < server/database/forum.sql
```

Хост и имя базы — те же, что в `NUXT_DB_HOST` / `NUXT_DB_DATABASE` (`/var/www/azimut/.env`).
Пока таблиц нет, форум отвечает `503 forum_unavailable` и показывает заглушку
«Форум скоро откроется», остальной сайт работает как обычно.

### Модель данных

- `forum_sections` — разделы: `name`, `description`, `sort` (меньше — выше).
  Счётчики тем/сообщений и последняя активность считаются запросом.
- `forum_topics` — темы: заголовок и тело **первого сообщения** хранятся здесь;
  `is_pinned`, `is_locked`, `view_count`; `reply_count`, `last_post_at`,
  `last_post_login` пересчитываются сервером при изменении ответов.
- `forum_posts` — ответы: `body`, автор, `created_at`, `updated_at` (редактирование).

Автор хранится и по `author_id`, и по `author_login` — имя остаётся видимым, даже
если мастер-аккаунт позже удалят.

## API

Базовый адрес — домен сайта. Изменяющие запросы защищены от CSRF (только со своего
сайта, cookie сессии `SameSite=Lax`). Ошибки — общие коды `cabinet.errors`.

| Метод и адрес                          | Доступ        | Назначение                                  |
|----------------------------------------|---------------|---------------------------------------------|
| `GET /api/forum`                       | публично      | Список разделов                             |
| `GET /api/forum/sections/<id>?page=N`  | публично      | Раздел и его темы (пагинация)               |
| `GET /api/forum/topics/<id>?page=N`    | публично      | Тема и ответы; увеличивает просмотры        |
| `POST /api/forum/topics`               | вошедший      | Создать тему `{ sectionId, title, body }`   |
| `PATCH /api/forum/topics/<id>`         | автор/админ   | Правка `title`/`body`; `isPinned`/`isLocked` — только админ |
| `DELETE /api/forum/topics/<id>`        | автор/админ   | Удалить тему вместе с ответами              |
| `POST /api/forum/topics/<id>/posts`    | вошедший      | Ответ `{ body }`; в закрытой теме — `403 topic_locked` |
| `PATCH /api/forum/posts/<id>`          | автор/админ   | Правка ответа `{ body }`                    |
| `DELETE /api/forum/posts/<id>`         | автор/админ   | Удалить ответ                               |
| `POST /api/forum/sections`             | админ         | Создать раздел `{ name, description, sort }`|
| `PATCH /api/forum/sections/<id>`       | админ         | Изменить раздел                             |
| `DELETE /api/forum/sections/<id>`      | админ         | Удалить **пустой** раздел (иначе `409 section_not_empty`) |

Пагинация: `?page=N` (1-based), по 20 тем/сообщений на страницу (`forumLimits.perPage`).
Ответы списков: `{ page, pages, total, ... }`.

Ограничения частоты: создание тем — 10/час, ответы — 30/час на мастер-аккаунт.
Длины: заголовок 3–150, сообщение 2–20000, название раздела до 100, описание до 255
(`shared/forum.ts`: `forumLimits`). Текст сообщений — обычный текст (HTML не
исполняется), переносы строк сохраняются.

Коды ошибок форума: `forum_unavailable`, `section_not_found`, `topic_not_found`,
`post_not_found`, `invalid_section`, `invalid_title`, `invalid_body`, `topic_locked`,
`section_not_empty` (тексты — `cabinet.errors`).

## Права и модерация

- Создавать темы и ответы может любой вошедший мастер-аккаунт.
- Автор и админ могут редактировать/удалять свои темы и сообщения; админ — любые.
- Только админ закрепляет (`isPinned`) и закрывает (`isLocked`) темы. В закрытой
  теме ответы отключены.
- Разделы создаёт/меняет/удаляет только админ (`/admin/forum`). Удаление возможно
  лишь для пустого раздела.
