# Стримы

Секция «Стримы AzimutLive» (`#streams` на главной) показывает плееры трансляций под заголовком:
два в ряд на широком экране, по одному на телефоне. Плееры 16:9 и подгружаются, когда посетитель
докручивает до секции.

## Как добавить стрим

Откройте `app/data/site.ts` и добавьте строку в массив `streams`:

```ts
export const streams: string[] = [
  'https://kick.com/gmhikaru',
  'https://www.twitch.tv/kaicenat',
]
```

- Одна строка — один плеер. Плееры идут в том же порядке, что и строки.
- В строку можно вставить **что угодно из списка ниже**: ссылку из адресной строки браузера,
  адрес плеера или весь код `<iframe>` из кнопки «Поделиться → Встроить». Переделывать ничего не нужно.
- Размеры, `frameborder`, `allowfullscreen` и прочие атрибуты из кода `<iframe>` игнорируются:
  оформление задаёт сайт.
- Пустой массив (`[]`) — плееров нет, остаются только заголовок и текст.
- Строки-дубли (один и тот же канал разными ссылками) показываются один раз.
- Нераспознанная строка просто не выводится. В режиме разработки (`npm run dev`) в консоли
  браузера будет предупреждение `[streams] не удалось распознать стрим…` с этой строкой.

Строки в кавычках `'…'`. Если вставляете код `<iframe>`, в нём двойные кавычки `"` — это нормально.
Одинарная кавычка внутри строки сломает файл: такие строки берите в обратные кавычки `` `…` ``.

## Площадки и форматы

Короткая запись `площадка:канал` работает для Kick, Twitch, YouTube и Rutube.

### Kick

Только прямой эфир канала. Записи (VOD) Kick встраивать не даёт.

| Что вставить                      | Пример                                         |
|-----------------------------------|------------------------------------------------|
| Ссылка на канал                   | `https://kick.com/gmhikaru`                    |
| Адрес плеера / код `<iframe>`     | `https://player.kick.com/gmhikaru`             |
| Коротко                           | `kick:gmhikaru`                                |

### Twitch

| Что вставить                      | Пример                                                     |
|-----------------------------------|------------------------------------------------------------|
| Ссылка на канал (прямой эфир)     | `https://www.twitch.tv/kaicenat`                           |
| Запись трансляции                 | `https://www.twitch.tv/videos/2283737371`                  |
| Адрес плеера / код `<iframe>`     | `https://player.twitch.tv/?channel=kaicenat&parent=…`      |
| Коротко                           | `twitch:kaicenat`                                          |

Twitch показывает плеер только на доменах из параметра `parent`. Сайт подставляет его сам
(текущий домен, в том числе `localhost`), так что `parent=www.example.com` из чужого кода не мешает.
Из-за этого плееры появляются после загрузки страницы в браузере, а не приходят в HTML с сервера.
Twitch работает только по `https`, на `localhost` — и по `http`.

Перед эфиром Twitch крутит свою рекламу («Catch … right after this ad break») — это нормально,
со стороны сайта она не отключается.

### YouTube

| Что вставить                         | Пример                                                    |
|--------------------------------------|-----------------------------------------------------------|
| Ссылка на видео или эфир             | `https://www.youtube.com/watch?v=dQw4w9WgXcQ`             |
|                                      | `https://youtu.be/dQw4w9WgXcQ`                            |
|                                      | `https://www.youtube.com/live/dQw4w9WgXcQ`                |
| Текущий эфир канала (по ID канала)   | `https://www.youtube.com/channel/UCX6OQ3DkcsbYNE6H8uQQuVA` |
| Код `<iframe>` / адрес `/embed/…`    | `https://www.youtube.com/embed/dQw4w9WgXcQ`               |
| Коротко                              | `youtube:dQw4w9WgXcQ` или `youtube:UC…`                   |

- Ссылка на конкретный эфир (`watch?v=…`, `/live/…`) показывает именно его. Когда эфир закончится,
  в плеере будет запись. Для каждого нового эфира ссылку нужно менять.
- Ссылка на канал `/channel/UC…` всегда показывает **текущий** эфир канала — удобно для постоянного
  стримера. Нужен именно ID канала, начинается с `UC`, 24 символа. Ссылки вида `youtube.com/@имя`
  **не работают**: YouTube не даёт встраивать эфир по @имени. ID канала: на странице канала
  «О канале → Поделиться каналом → Копировать идентификатор канала».
- Автор может запретить встраивание видео — тогда в плеере будет ошибка, сайт тут ни при чём.

### VK Видео

| Что вставить                           | Пример                                                         |
|----------------------------------------|----------------------------------------------------------------|
| Ссылка на видео или эфир               | `https://vkvideo.ru/video-220018529_456239435`                 |
|                                        | `https://vk.com/video-220018529_456239435`                     |
| Ссылка из ленты (`?z=video…`)          | `https://vk.com/club220018529?z=video-220018529_456239435`     |
| Код `<iframe>` / `video_ext.php`       | `https://vkvideo.ru/video_ext.php?oid=-220018529&id=456239435&hash=…` |

- Встраивается конкретное видео или эфир: в VK у трансляции такой же адрес `video…_…`, как у видео.
  Канала «всегда текущий эфир» у VK нет — для нового эфира ссылку нужно менять.
- Для закрытых или «только по ссылке» видео берите код `<iframe>` из «Поделиться → Экспортировать»:
  в нём есть `hash`, без него плеер не откроется.

### Rutube

| Что вставить                     | Пример                                                                 |
|----------------------------------|------------------------------------------------------------------------|
| Ссылка на видео                  | `https://rutube.ru/video/c6cc4d620b1d4338901770a44b3e82f4/`             |
| Ссылка на эфир                   | `https://rutube.ru/live/video/c6cc4d620b1d4338901770a44b3e82f4/`        |
| Приватное видео                  | `https://rutube.ru/video/private/c6cc…82f4/?p=ключ`                     |
| Код `<iframe>` / `/play/embed/…` | `https://rutube.ru/play/embed/c6cc4d620b1d4338901770a44b3e82f4`         |
| Коротко                          | `rutube:c6cc4d620b1d4338901770a44b3e82f4`                               |

Как у VK, встраивается конкретный эфир — для нового эфира нужна новая ссылка.

## Что не поддерживается

- Другие площадки (Trovo, Telegram, Facebook и т. д.) и произвольные `<iframe>` с чужих сайтов.
  Это сделано специально: из строки берётся только канал или ID видео, а адрес плеера сайт собирает
  сам. Поэтому вставленный код не может подгрузить на сайт постороннюю страницу.
- Скрытие каналов, у которых сейчас нет эфира. Офлайн-плеер показывает заставку площадки
  («оффлайн», последний эфир и т. п.). Чтобы скрывать такие каналы, нужен запрос к API площадок.

## Как устроено

| Файл                                       | Что там                                                         |
|--------------------------------------------|-----------------------------------------------------------------|
| `app/data/site.ts` → `streams`             | список стримов (строки)                                         |
| `app/utils/streams.ts` → `parseStream()`   | разбор строки: площадка, канал/ID и адрес плеера                |
| `app/components/section/SectionStreams.vue`| секция: заголовок, сетка плееров                                |
| `app/locales/ru.ts`, `en.ts` → `streams`   | заголовок и текст секции                                        |

Чтобы добавить площадку: допишите её в `StreamPlatform` и `streamPlatformNames`, а в `parse()` —
ветку для её домена. Функция должна возвращать адрес плеера, собранный из проверенных регулярным
выражением частей, а не исходную строку.
